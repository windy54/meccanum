# meccanum

I originally started by trying to integrate an ESP32-cam board with the pimoroni motor2040 board.

After lots of attempts I gave up, this code is in the folder esp32Camera.
The aim was to create a web page to control the robot and display video. 
With a line following mode as well as an automatic mode 
where it goes forward and uses a range sensor to navigate round objects.

The second folder contains an alternative approach which does work using a PICO W2 ro create the webpage.
Obviously no video.

I have re-used code from other people, hopefully I have acknowledged the sources, mainly Kevs robots and PIWARS conference for the line detection.

Perplexity.ai was used to debug my ESP32-cam code.
